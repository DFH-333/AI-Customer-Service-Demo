# 扣子上建一个能用的店铺客服 —— 照着点，20 分钟

准备：一个手机号 + 这个文件夹里的两个文件。
**顺序很重要：先建知识库，再建机器人。** 反过来会卡住。

---

## 一、注册

> ⚠️ **2026-10 更新**：扣子把产品拆成了三个站。**新注册的账号在 `www.coze.cn` 上建不了智能体和知识库** ——
> 官方原话：「扣子开发平台（低代码）不再向新注册用户开放，请前往**扣子编程**」。
> **入口改成 `https://code.coze.cn`**，下文所有「左边栏 → 资源库」的点击顺序照旧，只是要在这个站里点。
> 详见 `4-工作流搭建.md` 第二节。

浏览器打开 **https://code.coze.cn** → 手机号注册登录。免费。

> 如果你进去看到的是「扣子编程」那种满是代码的界面，找一下「回到旧版」——
> 我们要的是最普通的智能体，不要碰编程版。

## 二、先建知识库

1. 左边栏 → **资源库**
2. 上方找 **知识库** → **创建知识库** → 选 **文本数据**
3. 名字填：`老灶房客服`
4. **上传** `2-知识库.txt`（就在这个文件夹里）
5. 分段方式选 **自动分段**（不用手动调）
6. 往下找**检索设置**，按这个填：

| 参数 | 填什么 | 为什么 |
|---|---|---|
| 检索方式 | **混合检索** | 关键词 + 语义一起用，对中文小店问答最准 |
| 相似度阈值 | **0.75** | 低于这个分数就当"资料里没有"，宁可拒答 |
| 召回条数 | **4** | 给模型的资料，够了，多了反而乱 |

7. 保存，等它处理完（十秒左右）

---

## 三、建智能体

1. 左边栏 → **工作空间** → **创建智能体**
2. 名字：`老灶房·江湖菜 客服`，图标随便选一个，**创建**
3. 进到编辑页，找到 **人设与回复逻辑** 那个大框：
   - **把框里原本的占位内容全部删掉**
   - 打开 `1-人设提示词.txt`，**整段复制，粘进去**
4. 找到 **知识**（技能栏里的「知识」）→ 点 **+** → 选刚才那个 `老灶房客服` 知识库
5. **把「自动调用」打开**（不开的话它不会去查库）
6. 找到模型设置，把**随机性 / 温度调到 0.3 左右**（低一点，少胡说）
7. **不要开启联网搜索插件**，也不要加别的插件

> 第 7 条是坑：一开联网，它就不只用你的知识库了，会开始自己搜、自己编。

## 四、必须先测（别急着发布）

页面右边有「预览与调试」。在**建议问题**里加这几个，然后一个个点：

| 问它 | 期望结果 |
|---|---|
| 你们几点关门？ | 说出 22:30 打烊、21:45 最后点餐 |
| 有包间吗，能坐几个人？ | 6 个包间，8 到 20 人，订金 200 |
| 人均多少钱？ | 65 到 80 元 |
| 停车方便吗？ | 负二楼，满 100 免费停 3 小时 |
| 生日有什么优惠？ | 送一份红糖糍粑 |
| **你们店里有篮球场吗？** | **必须回「不太确定，帮您转人工」** |

- 前五个答错或答得含糊 → 知识库没传对，回去第二步
- **第六个它答了 / 开始编 → 人设提示词没粘全，回去第三步**

**第六个是验收标准。** 它必须会承认自己不知道，这个比前面五个加起来都重要。

## 五、发布 —— 第一步别碰微信

发布的时候你会看到一堆渠道：微信客服、微信公众号、企业微信、飞书、豆包、扣子商店……

**现在选「扣子商店」或者「分享链接」，拿到一个二维码就行。**

手机扫一下当场就能用，演示完全够。

### 为什么现在别碰微信

| 渠道 | 你要先有 | 时间 |
|---|---|---|
| 微信客服 | 企业微信 + **300 元认证** + 一个能通过主体校验的域名 | 审核 1–7 个工作日 |
| 微信公众号 | **认证服务号** + 腾讯云云函数做中继 | 更久 |
| 企业微信 | 企业微信 + 认证 | 中等 |

**你现在的客户连钱都还没付，一条都不值得做。**

而且这几样东西不是你在电脑前能点出来的 —— 300 块认证得客户自己出、域名主体得是他公司。
**这正好是你要跟客户谈的下一件事，不是你现在该解决的。**

## 六、顾客从哪儿找到它（入口）

**先说结论：顾客不会主动去搜一个 AI。你必须把它放在顾客已经在的地方。**

### 两种形态，不要混

**演示版（现在）** —— 顾客扫你的二维码 → 打开一个网页 → 直接聊
- 优点：现在就能用，零门槛
- 缺点：**顾客不在自己的微信里**，聊完就走，不会主动回来。
  **只适合演示，不能当交付。**

**真交付版（微信里）** —— 顾客在微信里点商家的「联系客服」→ 机器人先答 → 答不上来转人工
- 这才是真入口：**顾客本来就在微信里，什么都不用装**

### 扣子能发布到哪儿

以发布页面当时列出的为准，大致是这些：

| 渠道 | 顾客怎么找到它 | 门槛 |
|---|---|---|
| **分享链接 / 二维码** | 扫码或点链接 | 无 ← **演示阶段用这个** |
| **微信客服** | 微信里点商家的客服卡片 / 小程序里的「联系客服」 | 企业微信 + **300 元认证** + 域名主体校验，审核 1–7 天 |
| 微信公众号 | 关注公众号后直接发消息 | 认证**服务号** + 云函数做中继 |
| 企业微信 | 客户在企业微信里发消息 | 企业认证 |
| 豆包 / 扣子商店 | 在对应 App 里搜到 | 无，但**顾客得先装那个 App**，不现实 |
| 抖音小程序 | 抖音号里挂载 | 需审核 |

**一个坑**：微信客服渠道**不支持语音输入** —— 顾客发语音它听不懂。
到时候在店里贴一句「本店客服请用文字咨询」就绕过去了。

### 老板真正买的东西

不是"一个机器人"，是这句：

> **AI 先挡，挡不住再叫人。**

微信客服天然支持这个架构：机器人在前面接，转人工落到企业微信的真人身上，
而且**顾客那一头感觉不到切换**——他以为一直在跟店里的客服说话。

**这句话比任何功能都打动老板。** 因为老板真正的痛不是"没人回"，是
"前台一直在被同一个问题打断"。

### 现在你该把它放在哪

如果这家店已经有公众号 / 小程序 / 点评页 / 外卖卡片，
**二维码贴到那儿**——贴在顾客本来就会看的地方。

没有这些触点的话，就打印一张台卡放收银台。
**顾客不会为了一个 AI 多做一个动作，你要把它塞进他原本的动作里。**

## 七、客户点头之后

顺序是这样，别跳：

1. 让客户自己去办**企业微信认证**（300 元，他出，这是他的成本不是你的）
2. 认证明下来了，再走扣子的 **「微信客服」** 渠道
3. 那一步的界面和政策变得快，**到时候我查最新的、一步一步带你做**

---

## 八、换客户（10 分钟）

只改 `2-知识库.txt` 一个文件：

- 第一行 → 改成客户的名字
- 每个【话题】下面 → 换成客户自己的说法（写得越口语越好）
- 电话 → 直接写在里面，拒答时会自动带上

改完**重新上传一份新知识库**，然后把智能体的「知识」重新绑定到新的那份。

提示词里那句拒答话术里的电话号码，也要跟着改一下（在 `1-人设提示词.txt` 第 1 条）。
